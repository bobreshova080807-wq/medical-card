# Медицинская карта пациента

Задача 7 на 1 аттестацию по ООП.

## Описание модели

Система ведёт медицинские карты пациентов. Основные классы:

- **Patient** — пациент (идентифицируется номером полиса)
- **Doctor** — врач определённой специальности
- **Specialty** (enum) — специальность врача с номером кабинета и длительностью приёма
- **Appointment** — запись пациента на приём к врачу
- **Visit** — состоявшийся приём с диагнозом и назначениями
- **Medicine** — лекарственный препарат
- **ListMedicine** (enum) — стандартные лекарства с параметрами курса
- **Prescription** — назначение с курсом лечения
- **MedicalRecord** (sealed interface) — медицинская запись в карте
- **DiagnosisRecord** — запись о диагнозе
- **PrescriptionRecord** — запись о назначении

## Возможности

### Базовый уровень
- Запись на приём с проверкой занятости врача и рабочих часов кабинета
- Проведение приёма: диагноз + курс лечения
- История приёмов пациента за период
- Действующие назначения на указанную дату
- Исключение `ConflictExclusion` при конфликте расписания

### Повышенный уровень
- Поиск пересекающихся назначений по активному веществу
- Курс лечения: расписание приёма лекарства по датам и времени, построенное из назначения
